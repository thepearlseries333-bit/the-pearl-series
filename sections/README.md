# مجلد الأقسام

ضع هنا ملفات HTML التفاعلية الجاهزة، مع مراعاة:

1. اسم الملف يحتوي رمزًا عشوائيًا حتى لا يُخمَّن، مثل: `p3-9d41be7c.html`
2. أضف داخل `<head>` سطري الحارس:

```html
<style id="pearl-guard-style">body{visibility:hidden}</style>
<script type="module" src="../assets/js/section-guard.js" data-section="p3"></script>
```

3. سجّل المسار من لوحة الإدارة → «روابط الأقسام».

الملف `found-demo7f3a91.html` نموذج عملي جاهز للاطلاع.
